Metadata organised into the three tiers proposed by:
  Ward et al., Principles of the Battery Data Genome, Joule 6, 2253-2271 (2022), doi:10.1016/j.joule.2022.08.008

  metadata_primary.csv    minimal mandatory record, per cell
  metadata_secondary.csv  cell and electrode design
  metadata_tertiary.csv   simulation model parameters
  quality_audits.csv      closure audits: quality control on
                          the tertiary tier, against measurements
                          never used to build the parameter set

Provenance tags: [M] measured  [L] literature  [D] derived  [E] estimated
